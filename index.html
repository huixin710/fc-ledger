    本期分類花費

    各卡結帳日

    一筆消費要看入帳日落在結帳日前還後，才知道它進哪一期帳單。 結帳日之後刷的，這期帳單上不會有，下期才會來。

    未出帳 — 結帳後才刷的

    這些會出現在下一期帳單。本幣還沒填的，外幣用歷史平均匯率估（顯示成 ~金額）、 台幣直接用原幣金額，所以預算已經算進去了。

    待對帳 — 照理已出帳但沒填入帳日

    消費日已經早於結帳日，帳單上應該找得到了。點進去把入帳日（和本幣）補上，這裡就會清掉。

    貼上帳單，一次匯入

    從網銀或帳單 PDF 把明細那幾行直接複製貼上（Ctrl/⌘+A 全選整塊也可以）， 程式會自動抓日期、店名、金額。繳款那幾行會自動略過。

    ☁ 雲端同步（GitHub Gist）

    設定後每次儲存會自動把資料備份到你的私人 GitHub Gist（不對外公開）。手機和電腦用同一個 Token 就能互相同步。

    取得方式：github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)，建立一個只勾 gist 的 token 貼上即可（要用 Classic，不是 Fine-grained）。

    資料備份

    資料只存在這台裝置的瀏覽器裡（不會上傳）。換手機或清除瀏覽器資料前請先匯出。
