# FC 記帳本

粉絲俱樂部（FC）月額／年額費、扭蛋、周邊、專輯、線上演唱會等**海外刷卡消費**的記帳程式。
以 `FC.xlsx` 的欄位為藍本，純前端、手機優先、可離線使用。

* 資料**只存在你自己手機／電腦的瀏覽器**（localStorage），不會上傳到任何伺服器
* 支援民國年顯示（例：`115/04/06`）
* 可安裝到手機主畫面（PWA），離線也能開

---

## 功能

| 分頁 | 內容 |
|---|---|
| **總覽** | 本期總支出、筆數、手續費、平均／最大單筆；每月支出長條圖、分類佔比環圈圖、依藝人／信用卡的排行、依幣別的原幣與匯率統計 |
| **明細** | 搜尋 + 分類／卡別／幣別／藝人篩選、四種排序、依月份分組小計 |
| **訂閱** | 未來 90 天內到期／已逾期的續訂提醒；依「項目＋會員卡號」歸戶的年度固定支出估算 |
| **設定** | JSON／CSV 匯出匯入、自訂分類與信用卡、重置資料 |

上方的期間列可左右切換月份；**點一下中間的標籤**會在「月 → 年 → 全部期間」之間循環。

## 欄位對應（與原 Excel 一致）

| Excel | App |
|---|---|
| 消費日 | `date` |
| 入帳日 | `postDate` |
| （C 欄）品名 | `item` 項目 |
| 本幣 | `twd` |
| 幣別 | `currency` |
| 原幣 | `amount` |
| 手續費 | `fee` |
| 刷卡 | `card` |
| 備註 | `note` |
| 會員卡號 | `memberId` |
| 下次付款日 | `nextDue` |
| — | `category` 分類（新增） |
| — | `artist` 藝人／團體（新增） |

> 統計中的「總支出」＝ **本幣 + 手續費**。

## 匯入 / 匯出

* **匯出 CSV**：UTF-8 with BOM，Excel 直接開不會亂碼；日期以民國格式輸出。
* **匯入**：接受本程式匯出的 JSON 或 CSV。CSV 只要標題列有上表的中文欄名即可，日期可寫
  `115/04/06`、`2026-04-06`、`2026/4/6`、`2026.04.06` 都能解析。
* 匯入時會問你要**取代**現有資料還是**附加**在後面。

## 部署到 GitHub Pages

```bash
git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
git branch -M main
git push -u origin main
```

推上去後到 repo 的 **Settings → Pages**，把 *Source* 設為 `Deploy from a branch`、
分支選 `main` / `(root)`，存檔。約 1 分鐘後網址會是：

```
https://<你的帳號>.github.io/<repo 名稱>/
```

手機用 Chrome / Safari 開這個網址 →「加到主畫面」，就會像 App 一樣有圖示、全螢幕、可離線。

> repo 名稱若取作 `<你的帳號>.github.io`，網址就會是 `https://<你的帳號>.github.io/`（根目錄）。

## 更新網頁後手機沒變？

Service Worker 採「網路優先」，有網路時一定拿最新版。若想強制清乾淨，
改 `sw.js` 最上面的 `var CACHE = 'fc-ledger-v1';` 版本號再推一次即可。

## 注意

原 Excel 第 26 列 `PRIMAL FOOTMARK 2026 ONE OK ROCK` 的「本幣」欄為 `2`、且沒有入帳日，
看起來是還沒入帳。這筆的本幣**留空**，明細會顯示「待入帳」，也不會被算進任何統計；
帳單下來後在 App 內補上金額即可。

「本幣」欄本身是選填的：只要留空，那筆就當作尚未入帳處理。
