# FC 記帳本

追星（FC 月額／年額費、扭蛋、周邊、專輯、演唱會）加上日常消費的記帳、**預算規劃**與**分期追蹤**。
純前端、手機與電腦都能用、可離線。

* 資料**只存在你自己裝置的瀏覽器**（localStorage），不會上傳到任何伺服器
* 日期一律用民國年（例：`115/08/10`）
* 手機可安裝到主畫面（PWA）；電腦是左側導覽 + 多欄版面

---

## 四個分頁

| 分頁 | 內容 |
|---|---|
| **總覽** | 本期總支出、筆數、手續費、平均／最大單筆；每月支出長條圖（附「可花上限」虛線，超過會轉紅）、分類佔比、依卡別／藝人排行、依幣別的原幣與換算匯率、單筆最大的 8 筆 |
| **預算** | 這個月還能花多少、每天可花多少；收入 → 固定支出 → 分期 → 可自由支配的拆解（並標出訂閱已佔用多少、真正彈性的錢剩多少）；分期未繳完清單與預估繳清月份；訂閱續訂提醒與管理；本期分類花費 |
| **明細** | 搜尋 + 分類／卡別／幣別／藝人篩選、四種排序、依月份分組小計 |
| **設定** | **貼上帳單一次匯入**、CSV／JSON 備份、自訂分類與卡別 |

上方期間列可左右翻月，**點中間的標籤**會在「月 → 年 → 全部期間」循環。

## 預算怎麼算

```
每月可自由支配 ＝ 稅後月收入 − 每月固定支出 − 分期每月扣款 − 想存下的錢
               = 35,000 − 10,955 − 9,617 − 0 = 14,428
```

固定支出、分期都在「預算 → 調整收入與固定支出」裡自己維護。分期繳完了就把那筆刪掉，
可自由支配的額度會自動往上調。

### 訂閱

訂閱是一份**自己維護的清單**，不是從歷史紀錄推導出來的——否則停訂的會一直跳提醒，
剛訂還沒扣過款的又完全不會出現。在「預算 → 管理訂閱」裡：

* 停訂就把勾勾取消（歷史消費紀錄會留著，只是不再提醒、不算進未來估算）
* 剛訂的直接新增，會標「未扣款」直到帳單上出現同名項目
* 月費的下次扣款日由「最近一次實際扣款 + 1 個月」推算，所以「已過 N 天」等於在提醒你**這個月的還沒記到帳**

### 年繳型支出

保費、稅這種年繳的用兩段處理：在固定支出放每月該預留的金額（例如年繳 31,899 → 2,658），
再把它的分類加進「不計入每月預算的分類」。這樣實際付款那個月不會被算兩次，
但那筆錢仍然出現在總覽的實際支出裡。

## 貼上帳單匯入

設定頁最上面那塊。從網銀或帳單 PDF 把明細那幾行直接複製貼上即可，程式會抓日期、店名、金額，
「繳款」「轉帳」「分期本金／利息」那幾行會自動略過，「國外交易手續費／服務費」會併進上一筆。

因為各家欄位順序不同，要先選帳單格式：

| 格式 | 適用 | 欄位順序 |
|---|---|---|
| 一般 | 台新、國泰 CUBE、寰宇… | 消費日 → 入帳日 → 店名 → **台幣** → 折算日／消費地／幣別／外幣 |
| 聯邦 | 聯邦銀行 | **入帳日** → 消費日 → 店名 → 消費地／折算日／幣別／外幣 → **台幣** |

匯入後可以逐筆點開改分類。

## 欄位對應（與原 Excel 一致）

| Excel | App |
|---|---|
| 消費日 / 入帳日 | `date` / `postDate` |
| （C 欄）品名 | `item` |
| 本幣 / 幣別 / 原幣 / 手續費 | `twd` / `currency` / `amount` / `fee` |
| 刷卡 / 備註 / 會員卡號 / 下次付款日 | `card` / `note` / `memberId` / `nextDue` |
| — | `category` 分類、`artist` 藝人（新增） |

統計中的「支出」＝ **本幣 + 手續費**。「本幣」留空代表**尚未入帳**，明細顯示「待入帳」，
不列入任何統計；帳單下來後補上即可。

## 匯入 / 匯出

* **匯出 CSV**：UTF-8 with BOM，Excel 直接開不會亂碼；日期以民國格式輸出。
* **匯入**：接受本程式匯出的 JSON（含預算與分期設定）或 CSV。CSV 只要標題列有上表的中文欄名即可，
  日期 `115/08/10`、`2026-08-10`、`2026/8/10`、`1150810`、`08/10` 都能解析。
* 匯入時會問要**取代**還是**附加**。

## 部署到 GitHub Pages

```bash
git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
git push -u origin main
```

推完到 repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`、分支 `main` / `(root)`。
約一分鐘後網址是 `https://<你的帳號>.github.io/<repo 名稱>/`。
手機用 Chrome / Safari 開，選「加到主畫面」。

> 改版後手機沒更新？Service Worker 是網路優先，有網路一定拿最新版；
> 要強制清乾淨就改 `sw.js` 最上面的 `var CACHE = 'fc-ledger-vN';` 版本號再推一次。
